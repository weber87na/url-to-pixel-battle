# 成片驗收

驗收對象是已編碼的完整 MP4，不能只看 ImageGen sheet 或 render 前的 still。

## 素材／時間軸

- 來源網址、原片、實際幀率與長度保存；剪點都在來源內。
- 使用者指定句逐項對照，不漏關鍵前提、回應或句尾。
- 講者和反應者分開，無聲反應沒有假字幕配音；ASR 的未確認字詞不可變成確定事實。
- source clip 不超界、不倒放、不隱含變速；轉場 silence 明列。
- 每個人物八格內容有效，透明背景、固定比例；伸手完整，pose 切換不出現另一格人物。

## 可觀察的畫面結果

從最終 MP4 抽查本片實際使用的動作：喝水或物件接觸、蓄力→出手、受擊後仰、各種招式、反應、首尾、章節切換。來源沒有喝水或只有單章時，不為了驗收清單捏造橋段。

- 不能用單張圖位移／閃爍代替喝水、出招、受擊。
- 人物動作與音效對上 impact_at，血條回復／下降的目標正確。
- 招式清楚可見，對話框和關鍵字幕不被遮擋，沒有提前揭包袱。
- 完整台詞在相應說話段能讀完；不是永遠只顯示文字開頭。
- 任意兩位新角色能使用相同腳本；沒有遺留舊人物姓名或固定四章標題。

## 技術與音訊

- ffprobe 確認目標尺寸、fps、時長、影格數與預期音軌；完整解碼成功。
- 音訊與畫面總長一致，句首句尾沒有被 clip 截掉，聽得見原音。
- 混音沒有削波、雙重原音或突兀靜音。聲音數值只作輔助，不等於已逐句聽過。
- SRT 使用成片時間而非來源時間，沒有超過影片終點。

可保留 `qa/` 代表幀、contact sheet、ffprobe JSON 與簡短 audit。寫明抽樣範圍，不宣稱逐格／全片人工審查。

通過既定檢查後交付；只有新變動、失敗或具體未解問題才重跑對應項目，不重複大量轉錄或生圖。
